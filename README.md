Things I'm Working On

Web Retrieval Engine

I wanted to see how far I could take web search without making an LLM the center of everything.

The idea is simple:

Give it a question.

It breaks the question into different searches, finds relevant pages, fetches them, removes the useless parts, processes the actual content, compares the information, and produces an answer from what it found.

The interesting part is the whole pipeline.

Question
   ↓
Searches
   ↓
Web pages
   ↓
HTML
   ↓
Useful content
   ↓
Chunks / sentences
   ↓
Relevance
   ↓
Sources
   ↓
Answer

The goal is to make the whole thing fast enough that you don't sit there waiting for it.

Knowledge Synthesizer

This started with a different question:

If I already have the information, do I really need an AI model to find an answer inside it?

You can give the system a large amount of text and ask questions about it.

It breaks the text down, finds the parts that matter, compares them, and builds the response from the information that was actually provided.

No external search.

No API.

No LLM.

The project is mainly about seeing how much can be done with good text processing, retrieval, ranking, and deterministic logic.
